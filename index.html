About Me

Hi, I'm Youdahe. I build things that work, mostly backend and infrastructure. I care more about whether something holds up once it's running than whether it looks clever.

I'm a CS and statistics student at Minnesota State University, Mankato, graduating June 2028. So far I've interned at Medtronic, Medica, Liberty Mutual, and NMDP, and spent a semester as a machine learning research assistant at Gustavus Adolphus College, working on document intelligence. These days I'm on the data platform team at NMDP and learning a lot from it. I'm always looking to do more research, so if you have something going, I'd like to hear about it.

On my own time I'm building youdaheDB, a distributed database engine in Rust. It's written up in Algorythm, the publication of a 20,000+ member community of Black software engineers.

If you're a recruiter or hiring manager, there's a version of this page written for you: what people I've worked with have said, how my skills map to real projects, and what I'm hoping to work on next.
